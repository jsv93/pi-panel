Presence wake

A sensor wired to a GPIO pin, read by the panel itself — no Home Assistant and no network, so it still works when the server does not. BCM numbering, which is what pinout diagrams use. 0 turns it off.

GPIO PIN (BCM, 0 = OFF)
SENSOR
RE-TRIGGER INTERVAL (MS)
How often a pin held high may wake the screen again. PIR and mmWave set this for you — 30s and 10s.

Diagnostics reports what the pin is doing and when it last saw movement — aim the sensor by watching that. A panel installed before v0.8.1 needs its GPIO library once: sudo apt install -y python3-gpiozero python3-lgpio then sudo systemctl restart panel-agent. It shows as FAILED: ModuleNotFoundError until you do.
